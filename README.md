# Обработка обращений

Небольшой Python-скрипт разбирает пять готовых обращений из `messages.txt`.
Для каждого сообщения он печатает категорию и черновик ответа на русском языке.

## Как запустить

Требуется Python 3.8 или новее. Внешние библиотеки не нужны.

```bash
python process_messages.py
python process_messages.py --review
```

## Что получилось

Скрипт нормализует текст: убирает лишние пробелы, приводит к нижнему регистру, удаляет пустые строки и выравнивает варианты записи Wi‑Fi / Wi-Fi / wifi. Это важно, потому что в реальном трафике такие варианты встречаются часто и могут ломать простые проверки по строкам.

Категории задаются через словарь правил:

- `справка` — вопросы о получении справки, местонахождении и парковке;
- `жалоба` — сообщения об очередях, холодной еде, пропаже Wi‑Fi и проблемах;
- `другое` — остальные обращения, например запись на консультацию.

Шаблоны ответов также вынесены в словарь, чтобы их проще было расширять новыми сценариями без переписывания логики в нескольких местах.

## Пример ожидаемого вывода

```text
1. Обращение: как получить справку о месте учёбы?
   Категория: справка
   Черновик ответа: Справку о месте учёбы можно заказать в учебном офисе или через личный кабинет. Возьмите с собой удостоверение личности.

2. Обращение: в столовой очередь, еда холодная.
   Категория: жалоба
   Черновик ответа: Спасибо за сообщение. Передадим жалобу администрации столовой для проверки очередей и качества блюд.

3. Обращение: хочу записаться на консультацию завтра.
   Категория: другое
   Черновик ответа: Записаться на консультацию на завтра можно через преподавателя или учебный офис. Уточните, пожалуйста, предмет и удобное время.

4. Обращение: пропал wi-fi в корпусе b.
   Категория: жалоба
   Черновик ответа: Спасибо за сообщение. Передадим информацию технической службе для проверки Wi‑Fi в корпусе B.

5. Обращение: где парковка для гостей?
   Категория: справка
   Черновик ответа: Гостевая парковка расположена у главного входа. Пожалуйста, уточните на посту охраны доступные места.
```

Режим `--review` дополнительно проверяет, что категория допустима, ответ не пустой и написан по-русски. Это простой слой самопроверки качества для лёгкого проекта, без избыточной инфраструктуры.
