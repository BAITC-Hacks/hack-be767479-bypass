# Обработка обращений

Небольшой Python-скрипт разбирает пять готовых обращений из `messages.txt`.
Для каждого сообщения он печатает категорию и черновик ответа на русском языке.

## Как запустить

Требуется Python 3.8 или новее. Внешние библиотеки не нужны.

```bash
python process_messages.py
```

## Что получилось

Скрипт использует простые правила по ключевым словам:

- `справка` — вопросы о получении справки, местонахождении и парковке;
- `жалоба` — сообщения об очередях, холодной еде, пропаже Wi-Fi и проблемах;
- `другое` — остальные обращения, например запись на консультацию.

В выводе сохраняется текст обращения, затем его категория и подходящий черновик ответа. Ответы для пяти исходных сообщений сформулированы с учётом их содержания: для справки о месте учёбы указан способ получения, жалобы направляются ответственным службам, а для консультации предлагается уточнить предмет и время.
